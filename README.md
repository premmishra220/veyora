# Veyora - Full-Stack E-Commerce Platform

Veyora is a full-stack e-commerce web application built using the MERN stack.

## Features
- **Customer Portal:** User authentication, product catalog, cart, checkout, and order history.
- **Admin Panel:** Product inventory management and order tracking.

## Tech Stack
- Frontend: React.js, Redux, CSS
- Backend: Node.js, Express.js
- Database: MongoDB, Mongoose
- Auth: JWT
